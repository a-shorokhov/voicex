# Voicex

Локальная диктовка для macOS и статический сайт со скачиванием приложения. Репозиторий **приватный**. Сейчас подготовлены инструкции и планы; приложение и сайт ещё не реализованы.

## Две независимые части

| Папка | Задача | Начать с |
| --- | --- | --- |
| `landing/` | Сайт, установка, приватность, скачивание | `landing/AGENTS.md`, `landing/MVP.md`, `landing/PROMPT.md` |
| `application/` | Нативное macOS-приложение с локальным Whisper | `application/AGENTS.md`, `application/MVP.md`, `application/PROMPT.md` |

В каждой папке `PLAN.md` содержит подробное устройство и дальнейшее развитие, а `MVP.md` — конкретную задачу первого релиза. Общие решения находятся в `PROJECT.md`.

## Как начать два новых чата

Модель для обоих чатов: **GPT-6.1 Sol**, reasoning **Medium**.

Для последовательной работы можно открыть соответствующую подпапку и отправить содержимое её `PROMPT.md`.

Для одновременной работы в разных ветках создайте два чата в режиме **Worktree** от этого репозитория. Первый работает с `landing/` на `feat/landing-mvp`, второй — с `application/` на `feat/application-mvp`. У каждого worktree должна быть собственная копия файлов. После создания worktree используйте его подпапку, а не папку исходного checkout.

Если оба чата используют одну физическую папку, нельзя независимо переключать им ветки: активная ветка у такого checkout одна. Границы подпапок помогают разделить файлы, но не заменяют worktree.

Новые чаты пользователь создаёт самостоятельно. Автоматически запускать реализацию обоих компонентов не нужно.

## Что входит в первый MVP

- Apple Silicon, macOS 14+, русский интерфейс.
- Установка одной Whisper-модели кнопкой, включая токенизатор.
- Русская и английская диктовка после остановки записи.
- Удержание и повторное нажатие горячей клавиши.
- Вставка в исходное поле с ручным копированием при невозможности вставки.
- Работа без интернета после установки модели и перезапуска.
- Статический сайт без аккаунтов, платежей и серверного API.
- Первый DMG без Developer ID и нотариализации.

## Простой стек

Сайт: HTML, CSS, TypeScript, Vite. Приложение: SwiftUI, AppKit, AVFoundation, WhisperKit, KeyboardShortcuts. Настройки: UserDefaults. Backend, ORM, база и Docker не нужны.

## Подготовка среды реализации

- Для приложения: полный Xcode, совместимый с установленной macOS.
- Для сайта: Node.js 24.x и npm.
- Для работы с GitHub: Git и GitHub CLI либо обычный интерфейс GitHub.
- Пользователю готового приложения эти инструменты не требуются.

Команды сборки и запуска добавляются в README соответствующей части после появления рабочего проекта.

## Публикация пока отдельно

Последняя инструкция пользователя — сохранить репозиторий приватным. Бесплатный GitHub Pages не публикует сайт из приватного репозитория, а приватные Releases недоступны посетителю без доступа к репозиторию. Поэтому публичная публикация — отдельный незавершённый внешний этап. Не менять видимость и не создавать второй репозиторий автоматически. Варианты описаны в `PROJECT.md`.
