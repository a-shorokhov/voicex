# Landing MVP — исполняемая задача

## Результат

Готовый локально проверенный статический сайт Voicex: главная, установка, приватность, корректное состояние скачивания. Без дизайна как отдельной работы и без backend. Публичная публикация из private repo требует отдельного решения; не выдавать локальную сборку за опубликованный сайт.

## Зафиксированный стек

HTML + CSS + TypeScript + Vite + npm, Node.js 24.x. Без React, Next.js, Tailwind, UI-kit, CMS, router, database и API. Существующие планы при scaffolding сохранить.

## Задачи

- [ ] Создать package.json и package-lock.json только внутри landing.
- [ ] Добавить dev, preview, check и build; check проверяет TypeScript, build выпускает dist.
- [ ] Настроить Vite для index.html, install.html и privacy.html.
- [ ] Установить base `/voicex/`; внутренние ссылки и ресурсы учитывают префикс.
- [ ] Добавить lang=ru, title и description в каждую страницу.
- [ ] Реализовать содержание главной из PLAN.md: назначение, CTA, требования, как работает, функции MVP, локальность, первый запуск, FAQ, footer.
- [ ] Реализовать пошаговую установку, разрешения, скачивание модели и диагностику.
- [ ] Описать отсутствие Developer ID/нотаризации и ручную процедуру Apple.
- [ ] Реализовать privacy по фактическому поведению приложения.
- [ ] Добавить минимальную адаптивность, доступные focus-состояния и клавиатурную навигацию.
- [ ] В одном модуле хранить доступность, версию и download/checksum URL. Начальное available=false.
- [ ] До проверенного публичного DMG показывать «Релиз готовится», без активной закрытой/несуществующей ссылки.
- [ ] Не ссылаться на private repo как на доступный всем канал поддержки.
- [ ] Добавить build-only `.github/workflows/landing.yml` для релевантных изменений и PR; рабочая директория landing.
- [ ] Обновить README фактическими командами и шагами preview.

## Вне задачи

Фирменный дизайн, новые чаты/агенты, иллюстрации, видео, EN-локализация, домен, аккаунты, формы, платежи, аналитика и автоматическая публичная публикация. Не менять приватность репозитория.

## Acceptance

- [ ] npm ci, check и build проходят.
- [ ] Production preview запущен и проверен в браузере.
- [ ] Все три страницы открываются напрямую под /voicex/.
- [ ] Ресурсы и межстраничные ссылки работают с base.
- [ ] Основной текст читается с отключённым JS.
- [ ] Вёрстка проверена на 375, 768 и 1440 px; нет горизонтального overflow.
- [ ] Клавиатурой можно пользоваться ссылками и FAQ.
- [ ] Нет неподтверждённых заявлений, секретов и чужого branding.
- [ ] CTA честно показывает отсутствие публичного релиза.
- [ ] dist содержит только публично допустимые файлы сайта.

## После отдельного разрешения на публикацию

Настроить выбранный хостинг. Если выбран Pages, опубликовать только dist и проверить публичную прямую навигацию. После появления публичного DMG подтвердить скачивание без авторизации, затем активировать CTA и проверить версию/checksum. До выполнения этих шагов публичный выпуск не завершён.

## Отчёт агента

Указать реализованные пункты, команды и результаты проверок, локальный URL preview, внешние блокеры и минимальное действие интеграции для публичного релиза. Не утверждать, что сайт опубликован, если он только собран.
