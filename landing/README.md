# Voicex — сайт

Здесь будет статический сайт Voicex. Код сайта пока не создан.

## Перед началом

1. Прочитать `../PROJECT.md`, `AGENTS.md` и `MVP.md`.
2. Использовать Sol 6.1 Medium.
3. Для отдельного чата скопировать содержимое `PROMPT.md`.
4. Для параллельных веток использовать отдельный worktree.

`PLAN.md` содержит подробный план и дальнейшее развитие. `MVP.md` — текущую реализацию. Root-репозиторий private, публичная публикация пока не настроена.

## Среда и будущие команды

Node.js 24.x, npm. После создания проекта агент должен реализовать и проверить:

```sh
npm ci
npm run check
npm run build
npm run dev
npm run preview
```

Эти команды пока не работают: package.json появится при реализации. Сборка должна давать только статический `dist` и не требовать серверного приложения.

Дизайн — отдельная последующая задача. Сейчас нужен функциональный сайт, корректное содержание, инструкция установки и конфигурация скачивания.
