# Voicex — сайт

Готовый статический лендинг в выбранном пользователем направлении «Зелёный сад»: главная, установка и приватность. HTML, CSS, TypeScript, Vite, npm; без framework и backend. Дизайн и Image Gen ассеты реализованы по последующему прямому запросу пользователя.

Рабочий checkout: `/Users/alex/.codex/worktrees/voicex-landing/Voicex/landing`, ветка `codex/landing`. Приложение и root-документы не изменялись.

## Запуск

Нужны Node.js 24.x и npm. Из папки landing:

```sh
npm ci
npm run check
npm run build
npm run preview
```

Production preview: http://127.0.0.1:4173/voicex/ . Оставьте терминал запущенным; для остановки нажмите Ctrl+C.

Разработка с автоматическим обновлением: `npm run dev`, адрес http://127.0.0.1:5173/voicex/ . Порты фиксированы; если порт занят, команда явно сообщит об этом.

### Этот Mac без глобального Node/npm

При реализации использован встроенный Node.js 24.19.0 и npm 12.2.0 из официального registry. Node не устанавливался глобально. Можно использовать доступный runtime:

```sh
cd /Users/alex/.codex/worktrees/voicex-landing/Voicex/landing
VX_NODE=/Users/alex/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin
VX_PNPM=/Users/alex/.cache/codex-runtimes/codex-primary-runtime/dependencies/bin/fallback/pnpm
PATH="$VX_NODE:$PATH" "$VX_PNPM" --config.store-dir=/private/tmp/voicex-pnpm-store dlx npm run preview
```

В последней команде вместо preview можно использовать dev, build, check; для установки — `dlx npm ci`. Путь встроенного runtime зависит от установленной версии Codex. Обычный Node.js 24 с npm также подходит.

## Структура

- index.html, install.html, privacy.html — реальные HTML-страницы. Основное содержание и FAQ работают без JavaScript.
- src/style.css — адаптивность, стеклянные UI-элементы и CSS-анимации.
- src/main.ts — демонстрация диктовки и применение конфигурации релиза.
- src/release.ts — единственное место для available, version, downloadURL и checksumURL.
- public/assets/ — три оптимизированные WebP-иллюстрации Image Gen. Промпты и назначение — в ASSETS.md.
- vite.config.ts — три entrypoint и base /voicex/. Для другого префикса меняется только base; ссылки используют %BASE_URL%.
- ../.github/workflows/landing.yml — только установка зависимостей, TypeScript и сборка. Не публикует сайт.

Production dist содержит только три HTML, favicon, CSS/JS и изображения. Markdown, исходники, package-файлы и данные приложения не копируются.

## Анимация и текст

Буквы, заголовки и заметки — настоящий HTML-текст, а не надписи Image Gen. На изображениях нет декоративной кириллицы. Яблочко и M на концептуальном чипе возвращены по просьбе пользователя; это иллюстрация платформы, а не логотип Voicex.

В первом экране используется предоставленный пользователем прозрачный PNG белой траектории с двойной волной, ореолом и искрами. Он расположен поверх фона между капсулой записи и заметкой, покачивается только серединой через SVG displacement: амплитуда до 10 CSS px, период 6 секунд. Начало закреплено на верхней границе капсулы, конец — в области текста заметки; карта смещения нейтральна на обоих концах. Тёмно-зелёные вертикальные буквы движутся по центральной линии PNG и используют ту же карту смещения, что и волна. Порядок чтения фразы слева направо сохраняется. Пока вся фраза не долетела, заметка пустая; затем текст плавно вписывается по буквам и остаётся на три секунды, затем быстро стирается с конца по одному символу (28 мс на символ) перед новым циклом. Полёт ускорен в 5 раз относительно первого варианта: 1,24 секунды на прохождение траектории. При уменьшении движения показывается готовая фраза без полёта. Сайт не обращается к микрофону и не распознаёт речь посетителя.

Ручных переключателей нет. При prefers-reduced-motion смещение середины отключается. При скрытии вкладки или уходе первого экрана из области просмотра анимации останавливаются. Положение и масштаб PNG рассчитываются из положения капсулы и заметки без искажения пропорций. FAQ использует нативные details/summary. Шрифты — системные Georgia/Arial, без внешних запросов.

## Публикация и скачивание

Репозиторий private. Сайт работает локально и не опубликован. Публичный хостинг ещё не выбран; DMG готов к размещению вместе со статическими файлами сайта.

Установщик 0.1.0 включён в `public/downloads/` вместе с SHA-256. Все три кнопки скачивания работают и без JavaScript; `src/release.ts` содержит активную конфигурацию релиза. Поддерживаются пути файлов на том же сайте и внешние HTTPS URL. Размер DMG — 3 146 919 байт (3,15 МБ), модель не включена. Сборка ad hoc, без нотариального заверения Apple; рядом с кнопками есть ссылка на инструкцию первого запуска. Публикация сайта отдельно разместит эти файлы на выбранном хостинге.
