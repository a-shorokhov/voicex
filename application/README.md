# Voicex — macOS-приложение

Здесь будет нативная локальная диктовка Voicex. Исходный Xcode-проект пока не создан; эта папка подготовлена для отдельного агента.

## Перед началом

1. Прочитать `../PROJECT.md`, `AGENTS.md` и `MVP.md`.
2. Выбрать GPT-6.1 Sol, Medium.
3. Отправить в новый чат содержимое `PROMPT.md`.
4. Для параллельных веток использовать собственный worktree.

`PLAN.md` — архитектура и последующие этапы. `MVP.md` — исполняемый текущий объём.

## Среда

Полный Xcode, совместимый с установленной macOS. Целевая платформа приложения — macOS 14+ на Apple Silicon. Только Command Line Tools недостаточно для принятого Xcode-workflow.

Swift Package Manager управляет WhisperKit и KeyboardShortcuts. Настройки хранятся в UserDefaults, модель и токенизатор — внутри Application Support/Voicex. Python, Docker, база и сервер не нужны.

После реализации агент добавляет здесь точные команды сборки, XCTest, запуска .app, выпуска DMG и диагностики разрешений. Существующих команд запуска пока нет.

## Дистрибуция

Первый локальный установщик — `Voicex-macos-arm64.dmg` плюс `SHA256SUMS.txt`. Без Developer ID и нотариализации; ad hoc-подпись не заменяет их. Модель скачивается отдельно кнопкой в приложении, а не включается в DMG.

Репозиторий private. Загрузка файла в его Releases не делает установщик публичным. Публичная публикация требует отдельного решения пользователя; в этой задаче готовится локальный проверенный DMG.
