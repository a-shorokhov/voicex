# Voicex — локальная диктовка для macOS

Apple Silicon, macOS 14+. SwiftUI/AppKit, AVFoundation, WhisperKit 1.1.0, KeyboardShortcuts 2.4.0. Никаких серверов или ключей API. Распознавание начинается после остановки записи.

## Запуск

Откройте `build/release/Voicex-macos-arm64.dmg`, перенесите Voicex в Applications и запустите оттуда. Сборка подписана локально ad hoc, без Developer ID/нотаризации. Если macOS блокирует запуск, пользователь разрешает его вручную штатным способом; системные защиты не отключать.

Если при запуске не хватает разрешений или модели, открывается «Начало работы». Пройдите четыре шага: разрешите микрофон, включите Voicex в системном списке Универсального доступа, установите модель и выберите клавишу/режим/язык. Каждый шаг показывает актуальное состояние и ведёт к нужному действию. Кнопка проверки записывает голос в окне приложения; для первой вставки откройте текстовое поле другого приложения и используйте выбранную клавишу. Разрешения выдаёт пользователь в системных окнах. После замены ad hoc-сборки или переноса приложения может понадобиться выдать их снова.

Выберите текстовое поле в другом приложении. Control+Shift+Space включает запись; повторное нажатие останавливает её. В режиме «Удержание» отпустите комбинацию для остановки. Во время записи внизу по центру появляется отдельная компактная панель с настоящей амплитудой; она не становится активным окном. Escape и крестик отменяют сессию. Максимум — пять минут. Можно закрыть основное окно: приложение остаётся в строке меню.

Автовставка работает только при подтверждённой исходной цели и доступе Accessibility. Проверяются PID, тот же AX focused element, редактируемая роль и защищённый ввод; содержимое поля не читается. При изменённой/неизвестной/защищённой цели остаётся последний результат для ручного Copy. Команда Cmd+V не отправляет Enter. Совместимость с конкретными редакторами требует ручной проверки; статус «Команда вставки отправлена» не доказывает, что редактор принял текст.

Кнопка «Начать проверку» записывает настоящий микрофон, но оставляет результат внутри Voicex. Без Accessibility эта проверка и Copy доступны. Правые модификаторы, сочетания только модификаторов и Fn используют обработчик только `flagsChanged`; для работы в фоне нужен Accessibility. Настройка сочетания временно отключает глобальный триггер. Если выбран правый модификатор/Fn без доступа, показываются кнопки «Разрешить доступ» и «Использовать ⌃⇧Space». Когда macOS подтверждает доступ текущему процессу, приложение автоматически подключает обработчик в фоне. После обновления ad hoc-сборки может потребоваться полностью завершить приложение и повторно выдать доступ новой копии. Повторные проверки доступа не сбрасывают удерживаемую клавишу. Панель остаётся поверх других приложений и не получает клавиатурный фокус. Fn может пересекаться с назначенными системными действиями этой клавиши.

## Модель и данные

По явной кнопке скачиваются `large-v3-v20240930_626MB` из `argmaxinc/whisperkit-coreml` и токенизатор `openai/whisper-large-v3` в `~/Library/Application Support/Voicex`. После загрузки идёт подготовка Core ML; первый запуск может занять заметно больше времени. «Готова» означает успешную загрузку модели, а не просто наличие папки. Можно отменить, повторить установку или удалить свои файлы. При ошибке доступен сброс файлов.

Обычный запуск использует только локальные папки, `download: false` и строго локальный токенизатор, без сетевого fallback. Повреждённые файлы требуют явной переустановки. Core ML также управляет своим системным кэшем специализации.

Аудио — mono Float32 16 kHz, только в памяти. Текст не логируется и не сохраняется на диск. По отдельному переключателю история хранится только в памяти процесса (до 100 результатов); по умолчанию выключена. Последний результат также исчезает после выхода. При Copy/автовставке текст остаётся в системном clipboard. Отмена инвалидирует поздний результат; новая операция не стартует, пока вычисление предыдущей действительно не закончилось.

## Сборка и проверки

Полный Xcode:

```sh
cd application
xcodebuild -project Voicex.xcodeproj -scheme Voicex -configuration Debug -destination 'platform=macOS,arch=arm64' -derivedDataPath build/DerivedData test
Scripts/package-dmg.sh
```

На этой машине есть только Command Line Tools. Доступен SwiftPM fallback:

```sh
cd application
Scripts/build-preview.sh release
Scripts/check-preview.sh
Scripts/package-dmg.sh
# Полностью завершите уже запущенный Voicex перед обновлением:
Scripts/install-local.sh
open /Applications/Voicex.app
```

`Scripts/install-local.sh` заменяет остановленное приложение целым bundle, а не переписывает исполняемый файл работающего процесса. Скрипт не выдаёт и не сбрасывает системные разрешения.

Fallback в игнорируемом checkout зависимости отключает только Xcode Preview declarations и меняет поиск локализаций KeyboardShortcuts на `Contents/Resources` с сохранением CLI fallback. Штатный Xcode-проект получает оригинальные пакеты. Нужны Swift 5.10+ и SDK с macOS 14+. Первая сборка скачивает исходники пакетов; модель в сборку/DMG не входит.

`Scripts/check-preview.sh` проверяет реальные guards отмены/повторов/тишины/короткой записи/цели вставки без сети и микрофона. XCTest содержит те же сценарии и отказ при отсутствующем локальном токенизаторе. Workflow `.github/workflows/application.yml` выполняет Xcode build/test без моделей и микрофона, без публикации. Локально XCTest не запускался: в CLT отсутствует модуль XCTest.

Дополнительная интеграционная проверка уже установленной модели:

```sh
Scripts/check-model.sh
# Только нейтральный синтетический файл, язык ru/en/auto и ожидаемое слово:
Scripts/check-model.sh /tmp/synthetic.aiff ru документ
# Запрет сети только тестовому процессу, без изменения настроек Mac:
sandbox-exec -p '(version 1)(allow default)(deny network*)' build/model-checks /tmp/synthetic.aiff ru документ
```

Проверка не выводит распознанный текст. Не передавайте ей личные аудиозаписи. Результаты и незавершённая ручная приёмка — в `UI-VERIFICATION.md`.

Артефакты: `build/Voicex.app`, `build/release/Voicex-macos-arm64.dmg`, `build/release/SHA256SUMS.txt`. Лицензии зависимостей — `NOTICES.md`, также включены в приложение и DMG. Публичной публикации нет.

## Передача установщика на лендинг

`Scripts/package-dmg.sh` создаёт версионный `build/release/Voicex-0.1.0-macos-arm64.dmg`, стабильную локальную копию, `SHA256SUMS.txt`, `release.json` и копию `RELEASE-HANDOFF.md`. Внутри DMG — Voicex.app, Applications shortcut, пользовательская `INSTALL.txt` и notices. Точный размер и SHA-256 генерируются из итогового файла.

Агент сайта получает DMG и инструкции из `RELEASE-HANDOFF.md`; сборка сама ничего не публикует и не меняет landing. Скачать установщик и скачать модель — разные шаги. Для первого запуска через интернет остаётся ограничение ad hoc/без нотариального заверения Apple; инструкция установки объясняет штатный путь подтверждения. Проверка копирования из DMG не заменяет приёмку первого запуска на другом Mac с Gatekeeper.
