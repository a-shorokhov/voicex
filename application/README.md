# Voicex — нативный визуальный каркас

SwiftUI/AppKit, Apple Silicon, macOS 14+. Это первый интерактивный этап: реальные окна и элементы управления, без записи микрофона и распознавания. Приложение не обращается к сети.

## Что доступно

- Отдельная компактная шалфейная панель навигации с hover-подсветкой и плавным выделением; пять разделов: Диктовка, Основные настройки, Модели диктовки, История, Начало работы.
- Проверка интерфейса: запуск → индикатор и таймер → остановка → обработка → нейтральный тестовый текст. Отмена прекращает операцию.
- Реальное копирование тестового текста в системный clipboard.
- Демонстрационные установка с прогрессом, отмена и удаление модели. Файлы модели не скачиваются.
- Основные экраны помещаются в окно без общего скролла; у заполненной истории прокручивается только список. Сочетание выбирается в небольшом полупрозрачном popover у кнопки. Язык, режим и выбор сочетания клавиш сохраняются в UserDefaults. Глобальная горячая клавиша пока не обрабатывается.
- История по умолчанию выключена. При включении тестовые результаты хранятся только в памяти текущего процесса; очистка доступна с подтверждением.
- Начало работы с демонстрационными состояниями разрешений. Системные доступы не запрашиваются.
- Меню в строке macOS: открытие окна, настройки, выход.

Стеклянные поверхности выполнены через NSVisualEffectView и SwiftUI Material. Декоративные растровые ассеты не используются. При Reduce Transparency основной фон становится непрозрачным. Макеты находятся в Design/.

## Сборка и запуск на этом Mac

На момент проверки установлен Swift в Command Line Tools, полного Xcode нет. Для текущего каркаса зависимостей нет, поэтому доступна локальная сборка:

```sh
cd /Users/alex/.codex/worktrees/voicex-application/Voicex/application
./Scripts/build-preview.sh
open build/Voicex.app
```

Результат: `build/Voicex.app`, локальная ad hoc-подпись. Скрипт не требует установки библиотек, скачивания модели или Developer ID.

## Xcode

Обычный `Voicex.xcodeproj` с общим scheme `Voicex`. После установки полного Xcode:

```sh
xcodebuild -project Voicex.xcodeproj -scheme Voicex \
  -configuration Debug -derivedDataPath build/DerivedData build
open build/DerivedData/Build/Products/Debug/Voicex.app
```

Проверка логики демонстрационных состояний (без микрофона и модели):

```sh
./Scripts/check-preview.sh
```

Xcode-сборка пока не запускалась: доступен только Command Line Tools. XCTest target и WhisperKit/KeyboardShortcuts будут добавлены на этапе реальной диктовки. Для статического визуального каркаса отдельный тестовый framework не создавался.

## Ограничения этого этапа

Результат проверки — фиксированная нейтральная фраза, а не распознанная речь. Статусы модели и разрешений с отметкой «демо» не доказывают готовность системы. HUD пока находится в основном окне, отдельный nonactivating panel будет нужен при интеграции с другими приложениями. Нет реального microphone input, установки Whisper, глобального hotkey, автоматической вставки, постоянной истории, DMG и публикации.

Системные проверки диктовки, offline cold start с установленной моделью, permissions, безопасная вставка и установка из DMG относятся к следующему этапу. Подробные результаты текущей проверки — в UI-VERIFICATION.md.
