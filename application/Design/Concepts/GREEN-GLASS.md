# Voicex — зелёное мягкое стекло

Концепт согласования внешнего вида, сгенерирован встроенным image_gen по референсу лендинга.

Палитра: ivory #F7F4E9, forest #123D28, sage #A8B58B, olive #80915C.

Реализация: SwiftUI/AppKit, системная типографика и символы, полупрозрачные материалы, мягкие непрерывные скругления. Декоративные растровые ассеты не нужны. Размер HUD в приложении ориентировочно 300×64 pt. У модели не должно быть выбора из списка: в MVP одна фиксированная модель. Статусы разрешений на картинке демонстрационные; приложение проверяет реальные разрешения. Обеспечить читаемость при Reduce Transparency/Increase Contrast.
