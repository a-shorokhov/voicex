# Voicex — экраны с боковой навигацией

Сгенерированы встроенным image_gen по запросу пользователя. Это дизайн-макеты, не реализованные экраны. История показана как новая опциональная функция, выключенная по умолчанию; реализация хранения не добавлена. В MVP одна модель. Размеры, типографика, реальные статусы и контраст уточняются при переносе в SwiftUI/AppKit.
