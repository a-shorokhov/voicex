# Проверка визуального каркаса — 4 октября 2026

## Автоматические проверки

- Сборка `Scripts/build-preview.sh` через установленный Swift 6.3.2, arm64, deployment target macOS 14: прошла.
- Проверка локальной ad hoc-подписи `codesign --verify --deep --strict`: прошла.
- `plutil -lint` для Info.plist и project.pbxproj: прошла.
- `git diff --check` для отслеживаемых изменений: прошла.
- `Scripts/check-preview.sh`: прошёл. Проверяет запрет старта без модели, установку/отмену, запрет параллельной записи/обработки и удаления занятой модели, отмену позднего результата, успешный результат/историю и удаление модели. Проверки не используют микрофон, сеть или реальные веса. Это небольшой самостоятельный executable, без нового тестового framework.

## Проверено через Computer Use в работающем .app

- Все пять разделов открываются; переход «Перейти к установке» работает.
- В исходном состоянии нет результата, кнопка копирования недоступна.
- Демонстрационная установка: появляется прогресс, можно отменить, состояние возвращается в «Не установлена». Повтор доходит до «Готова · демо».
- Удаление демомодели: есть подтверждение, после действия снова доступна установка.
- Проверка диктовки: старт, таймер/HUD, остановка, появление тестового результата и подтверждение «Скопировано» после копирования.
- Отмена записи: HUD исчезает, доступен повторный старт, нового результата нет.
- История: включение, пустое состояние, появление синтетического результата, очистка с подтверждением и возвращение к пустому состоянию.
- Настройки: выбор RU, режим удержания, смена сочетания на ⌥ Space, открытие/закрытие листа настроек сочетания.
- Перезапуск: язык и режим сохраняются; выбранное сочетание видно после следующего перезапуска. Модель, разрешения, результат и история демосессии не сохраняются.
- Начало работы: действие микрофона открывает объяснение демонстрации и помечает шаг выполненным; переход к проверке доступен при готовой демомодели.
- Выход из приложения и повторный запуск работают.

При захвате экрана Computer Use несколько раз вернул ошибки ScreenCaptureKit; подключение восстанавливалось повторным выбором приложения. Первичный скриншот выявил перенос длинного пункта навигации; ширина панели увеличена, подписи ограничены одной строкой. Скриншоты при фоне приложения иногда показывали только миниатюру окна, поэтому детальная визуальная приёмка финальной версии пользователем ещё нужна.

## Не проверено или не реализовано на этом этапе

- Отмена во время обработки не была зафиксирована через Computer Use: AX-захват возвращал уже завершённое состояние. Этот переход и запрет позднего результата проверены напрямую автоматическим тестом AppModel.
- Отдельные действия menu bar, открытие System Settings и второй демонстрационный шаг разрешений не проверены вручную.
- Reduce Transparency и Increase Contrast не проверялись вручную; основной фон учитывает Reduce Transparency.
- Xcode-сборка и XCTest не запускались: полного Xcode на Mac нет. Project и shared scheme созданы, их сборку необходимо проверить после установки Xcode.
- Совместимость с macOS 14 не проверялась на отдельном Mac: установленный deployment target не заменяет такую проверку.
- Настоящие microphone/Accessibility permissions, реальный Whisper, offline cold start с весами, глобальные горячие клавиши, системная вставка и DMG не реализованы в рамках визуального этапа.
