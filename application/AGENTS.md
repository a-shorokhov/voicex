# macOS application agent

Рабочая область: `application/**`. Единственное разрешённое исключение — `.github/workflows/application.yml`, когда появится рабочая сборка. Прочитай корневые `AGENTS.md` и `PROJECT.md`, затем локальный `MVP.md`.

- Модель: GPT-6.1 Sol, Medium. Ветка: `feat/application-mvp`, отдельный worktree при параллельной работе.
- Apple Silicon M1+, macOS 14+, русский интерфейс; проверяем русский и английский ввод.
- Стек: стандартный Xcode app, SwiftUI, нужные AppKit/AVFoundation API, WhisperKit, KeyboardShortcuts, UserDefaults, XCTest.
- Никаких backend, локального HTTP API, Python sidecar, Docker, ORM, database, cloud ASR, аккаунтов и API-ключей.
- Подключай только продукт WhisperKit из Argmax OSS; не подключай umbrella/TTS/diarization/server.
- Одна локальная модель, одна операция диктовки, без отдельных LLM, истории, Parakeet и streaming-вставки в MVP.
- Сначала доведи запись → распознавание → показ текста, затем hotkey и вставку.
- UI на main actor; сериализуй экземпляр WhisperKit, не передавай его между параллельными задачами.
- Не создавай DI-container, универсальный engine protocol, event bus и слои для будущих функций. Небольшие подмены для реальных тестов допустимы.
- Веса и токенизатор хранятся локально; после установки холодный запуск должен работать без сети.
- Нет постоянных аудиофайлов и истории; не логируй текст диктовки и содержимое чужих полей.
- Не вставляй в новую/непроверенную/защищённую цель, не отправляй Enter. При проблеме — последний результат и ручное копирование.
- Не меняй `landing/` и root-контракт. Не публикуй Releases и не меняй private-видимость без отдельного запроса.
- Пользователь сам выдаёт системные разрешения и вручную разрешает запуск неподписанной сборки. Не отключай системные защиты.

После создания проекта обнови README реальными xcodebuild-командами и скриптами Release/DMG. Unit-тесты не должны скачивать модель или требовать микрофон. Ручные offline, permission, paste и installer проверки обязательны; честно указывай, какие не выполнены.

Не реализуй roadmap из PLAN.md. Итог: рабочий MVP, локальный DMG, результаты проверок и точные внешние блокеры.

По указанию пользователя: делай локальный коммит своих изменений в application после завершения крупного этапа или существенного набора правок и проверок. Мелкие изменения отдельно не коммить. Не включай build outputs и приватные данные; не выполняй push без запроса.

Уточнение пользователя от 5 октября 2026: агенту явно разрешено после этой и следующих локальных сборок восстанавливать прежний Accessibility-доступ только для Voicex (адресный `tccutil reset Accessibility io.github.a-shorokhov.voicex` и включение доступа новой копии через системный UI). Другие разрешения и системные защиты не менять. Это уточнение заменяет требование ручной выдачи именно этого уже разрешённого доступа; при запросе пароля/Touch ID действие завершает пользователь.
