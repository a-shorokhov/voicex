Voicex — установка на Mac

Требования: Mac с Apple Silicon (M1 или новее), macOS 14 или новее.

1. Если Voicex уже работает, выберите «Выйти» в его меню в строке меню.
   Закрытие основного окна не завершает приложение.
2. Перетащите Voicex.app в папку Applications рядом с этой инструкцией.
   При обновлении подтвердите замену прежней копии.
3. Запустите Voicex из папки «Программы» и извлеките установочный диск.
4. В «Начале работы» разрешите микрофон и вставку текста через системный
   список доступа, установите модель и выберите клавишу/режим записи.
   Для установки модели нужен интернет: сама модель около 626 МБ,
   дополнительно загружаются файлы токенизатора и создаётся кэш подготовки.
5. Поставьте курсор в текстовое поле другого приложения. По умолчанию
   Control + Shift + Space запускает запись, второе нажатие останавливает её.
   После распознавания текст вставится в исходное поле.

Внизу появится маленькая панель с амплитудой. Escape или × отменяют запись.
Оставьте курсор в исходном поле до завершения распознавания. Если вставка
недоступна, откройте «Диктовка» и нажмите «Копировать».

Первый запуск этой версии

Это локальная сборка ad hoc, без Developer ID и нотариального заверения
Apple. macOS может заблокировать приложение, скачанное из интернета.
Если вы доверяете источнику этой копии, после попытки запуска откройте
«Системные настройки → Конфиденциальность и безопасность» и подтвердите
открытие Voicex штатной кнопкой «Всё равно открыть» / «Открыть».
Пароль или Touch ID подтверждает пользователь. Не отключайте Gatekeeper
и не удаляйте карантин командами Terminal.
Инструкция Apple: https://support.apple.com/ru-ru/102445

После обновления разрешения может понадобиться выдать новой копии снова.
Само приложение показывает недостающий доступ в «Начале работы».

Данные и удаление

После установки модели распознавание работает локально без интернета.
Голос и результаты не сохраняются на диск; временная история исчезает
после выхода. При копировании или вставке текст остаётся в буфере обмена.

Для удаления модели используйте «Модели диктовки → Удалить модель».
Для удаления приложения завершите Voicex и переместите его из «Программ»
в Корзину. Удаление приложения само по себе не удаляет файлы модели.
