# Установщик для агента лендинга

Готовые файлы находятся в `application/build/release/` этого worktree.

- Размещать на сайте: `Voicex-0.1.0-macos-arm64.dmg`.
- `release.json` содержит точный размер в байтах, SHA-256, версию и требования.
- `SHA256SUMS.txt` можно разместить рядом для проверки загрузки.
- `Voicex-macos-arm64.dmg` — идентичное содержимое со стабильным локальным именем.

Кнопка сайта: «Скачать для Mac». Указать: версия 0.1.0, Apple Silicon M1+,
macOS 14+, установка модели при первом запуске (≈ 626 МБ плюс дополнительные
файлы). Размер самого установщика брать из release.json, не смешивать его
с размером модели.

DMG содержит приложение, ссылку Applications, инструкцию установки и notices.
Пользователь открывает DMG, переносит Voicex в Applications и запускает его
оттуда. Настройка разрешений и модели объясняется в «Начале работы».

Это ad hoc-сборка без Developer ID и нотариального заверения Apple.
Рядом с загрузкой нужна видимая инструкция первого запуска из INSTALL.txt;
не обещать установку без предупреждений macOS или «проверено Apple».

Публиковать только DMG/контрольную сумму и нужные публичные метаданные.
Не размещать исходники, приватные диагностические файлы или модель.
Путь/URL размещения выбирает агент сайта. Этот этап сам ничего не публикует.

Воспроизведение: `cd application && Scripts/package-dmg.sh`.
